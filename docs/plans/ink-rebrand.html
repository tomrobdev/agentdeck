Ink: the high contrast rebrand

High contrast light is now the default theme (commit 58a7c88). Ink is the look that goes with it: black on white, hard edges, one blue accent, and a new mark and lowercase wordmark. This plan ports the design canvas (https://claude.ai/artifact/CCSu6sVSZCjKqtR9FMvn4r) into the dashboard in three steps, each its own task.

The look, in numbers

Part Ink (high contrast) Other themes
Colours Unchanged: the contrast theme's tokens in themes.css already are the Ink palette. Unchanged
Corner radius 2px on buttons, inputs, cards, chips, pills, the segmented control and popovers As today (6px, 8px, 999px)
Row rules 1px var(--text) between list rows and under card heads var(--border)
Frame edges 2px var(--text) under the header and above the status bar 1px var(--border)
Status chips and pills Outlined, 1.5px in the status colour, no tint; only running keeps a 14% tint As today
Shadows None on popovers and modals; a 2px var(--text) border instead As today
Type No web fonts. --font-sans and --font-mono stay the system stacks. Task #ids, meter percentages and shas use --font-mono in every theme.

Shape differences between themes go through custom properties set per theme in themes.css (for example --radius-ui, --rule, --edge, --pill-tint), read by style.css, so a theme switch still needs no rebuild. daemon/test/themes.test.ts requires every theme to define the same tokens in light and dark, so each new token goes in every theme rule, including the system dark copies.
