Plan files: a plan format AgentDeck reads and shows on the task

Plans are HTML pages, readable as they are. Mark the title, summary and steps with data attributes so the daemon can parse them with no dependency, attach them to their task, and show the steps and their status on the task's Overview, with the whole page one click away. Written 2026-10-19 on branch dashboard-views.

The format

<html data-agentdeck-plan="1"> marks a plan, <p data-plan-summary> its summary, and each <section data-plan-step data-status="todo|doing|done|blocked|skipped"> a step, titled by its first heading. The rest is free HTML. The full spec is docs/plan-format.md; this page is written in the format.

Decision Why
Data attributes on ordinary HTML The plans in docs/plans/ are already HTML pages. Attributes keep them free-form for a person and need no parser library.
Store the HTML, parse on read The parser can improve without a migration, and a plan is small next to the work of reading it from git.
A sandboxed frame with no scripts A plan is written by an agent. It may style itself but never run code in the dashboard.

1 · Parser

done

domain/plan/plan.ts: parsePlan drops comments, scripts and styles, checks the marker, and reads the title, summary and steps. Unknown statuses read as todo.

2 · Store

done

Migration step 7 adds task_plans, one row per task and name. db/plans.ts upserts by name, moves updated_at only when the HTML changes, and replaces a task's branch plans as one unit.

3 · Collect and attach

done

After every run the worker reads the plans the branch added or changed under docs/plans/. agentdeck attach <task> [plan.html] and POST /api/tasks/:id/plans attach one by hand. The task detail lists them; GET /api/tasks/:id/plans/:plan returns the HTML.

4 · Worker prompt

done

The worker's system prompt tells it where plans go and which attributes to use, and to keep each step's status current.

5 · Plan card

done

PlanCard.vue on Overview: title, progress, summary and steps. A step with an id opens the page at that step; the page shows in a frame sandboxed without scripts.
